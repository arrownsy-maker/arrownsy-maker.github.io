개인정보처리방침

최종 수정: 2026-11-09

mini-home은 운영자 본인이 자기 Google 계정의 메일함을 정리하려고 만든 개인용 도구입니다. 다른 사용자에게 제공하지 않습니다.

사용하는 데이터

  • Google 권한 범위: gmail.modify
  • 메일을 읽어 광고·스팸으로 보이는 대량 발송 메일을 골라 휴지통으로 옮기고, 운영자에게 요약 알림을 보냅니다.
  • 메일 보내기, 영구 삭제, 라벨·필터 변경은 하지 않습니다.

처리와 보관

  • 메일 내용은 운영자 집의 서버에서 로컬 모델로만 처리하며, 외부 AI 서비스나 제3자에게 보내지 않습니다.
  • 메일 본문을 따로 저장하지 않습니다. 인증 토큰은 그 서버에만 보관합니다.
  • 데이터를 판매하거나 광고에 쓰지 않습니다.

Google API 서비스 사용자 데이터 정책

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

권한 철회

Google 계정 → 서드 파티 앱 및 서비스에서 언제든 접근 권한을 해제할 수 있습니다.

Privacy Policy (English)

mini-home is a personal tool built by its owner to tidy their own Gmail inbox. It is not offered to other users.

  • Scope used: gmail.modify. Messages are read to identify bulk promotional/spam mail, which is moved to Trash, and a summary is sent to the owner.
  • It never sends mail, permanently deletes mail, or changes labels or filters.
  • Mail content is processed only on the owner's home server by a local model. It is not sent to external AI services or any third party, not stored, not sold, and not used for advertising.
  • The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at myaccount.google.com/permissions.
